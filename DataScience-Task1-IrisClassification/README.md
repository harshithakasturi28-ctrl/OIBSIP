# Iris Flower Classification

## OIBSIP Data Science Internship - Project 1

### Objective

The objective of this project is to build a machine learning classification model that predicts the species of an Iris flower based on its sepal and petal measurements.

### Dataset

The project uses the Iris dataset, which contains measurements of sepal length, sepal width, petal length, and petal width for three Iris flower species.

### Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### Machine Learning Algorithm

- K-Nearest Neighbors (KNN)

### Project Workflow

1. Imported the required Python libraries
2. Loaded the Iris dataset
3. Explored and analyzed the dataset
4. Visualized the data using Seaborn
5. Split the dataset into training and testing sets
6. Trained the KNN classification model
7. Evaluated the model
8. Tested the model with new flower measurements
9. Predicted the Iris flower species

### Result

The KNN classification model achieved **100% accuracy** on the test dataset.

The model was also used to predict the species of new flower measurements.
