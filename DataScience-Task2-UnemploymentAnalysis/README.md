# Unemployment Analysis with Python

## OIBSIP Data Science Internship - Project 3

### Objective

The objective of this project is to perform exploratory data analysis on unemployment data from India and identify regional and temporal trends, with particular focus on changes during the COVID-19 period.

### Dataset

The project uses the **Unemployment in India** dataset, containing unemployment, employment, and labour participation information for different regions of India from May 2019 to June 2020.

### Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

### Project Workflow

1. Loaded the unemployment dataset
2. Inspected the shape and columns of the dataset
3. Checked for missing values
4. Removed completely empty rows
5. Cleaned column names
6. Converted the date column to datetime format
7. Performed descriptive statistical analysis
8. Calculated region-wise average unemployment rates
9. Analyzed month-wise unemployment trends
10. Compared unemployment rates across three regions
11. Identified the top 10 regions with the highest average unemployment rate
12. Created a correlation heatmap
13. Compared pre-COVID and post-COVID employment conditions
14. Interpreted the major findings

### Key Findings

- Unemployment rates varied considerably across different regions of India.
- Unemployment changed noticeably over the period from 2019 to 2020.
- Different regions showed different unemployment patterns over time.
- The top 10 regions had relatively higher average unemployment rates.
- The correlation analysis showed relationships between unemployment, employment, and labour participation.
- Average unemployment increased from approximately **9.51% before COVID-19 to 17.77% during the post-COVID period**.
- Average estimated employment and labour participation decreased during the post-COVID period.
