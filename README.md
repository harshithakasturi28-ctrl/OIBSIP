# OIBSIP - Data Science Internship

This repository contains the projects completed during my **Oasis Infobyte Data Science Internship**.

## 📁 Project 1: Iris Flower Classification

### 📌 Objective
Build a Machine Learning model to classify Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

### 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### 🤖 Machine Learning Algorithm
- K-Nearest Neighbors (KNN)

### 📊 Project Workflow
- Imported required libraries
- Loaded the Iris dataset
- Explored and analyzed the dataset
- Visualized the data using Seaborn
- Split the dataset into training and testing sets
- Trained the KNN classifier
- Evaluated the model
- Predicted the species of new flower samples

### ✅ Result
The model achieved **100% accuracy** on the test dataset.
